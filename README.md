# XTTP
A new protocol, like https:// or http:// now, we has xttp://

# How to use?
in MD files
<pre>[xttp://YOUR_LINK_YOU_WANT_HERE](https://nbc-nu.github.io/XTTP/?redirect=https://nbc-nu.github.io/XTTP/host?l=YOUR_HTML_HERE)</pre>
in HTML files
<pre>a href="https://nbc-nu.github.io/XTTP/?redirect=https://nbc-nu.github.io/XTTP/host?l=YOUR_HTML_HERE">xttp://YOUR_LINK_YOU_WANT_HERE<\a</pre>
